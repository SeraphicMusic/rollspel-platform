# Konverteringsguide: Mutant

## Mutant: År Noll ↔ DoD 1991

### Attributmappning
| Mutant | DoD | Kommentar |
|--------|-----|-----------|
| STY | STY | Direkt motsvarighet |
| KYL | PSY | Ungefärlig motsvarighet |
| SMI | SMI | Direkt motsvarighet |
| SKP | INT | Ungefärlig motsvarighet |
| — | FYS | Fördela mellan STY och KYL |
| — | KAR | Fördela till SKP |

### Omräkningsformel (Mutant → DoD)
- Mutant använder 2-5, DoD använder 3-18 (3T6)
- Formel: `DoD-värde = (Mutant-värde - 1) * 4.5 + 3`
- Eller tabell: 2 → 3-6, 3 → 7-10, 4 → 11-14, 5 → 15-18

### Färdighetsmappning
- Mutant 0 → DoD FV 1-5
- Mutant 1 → DoD FV 6-10
- Mutant 2 → DoD FV 11-15
- Mutant 3 → DoD FV 16-20

### Konceptmappning
| Mutant-koncept | DoD-motsvarighet |
|----------------|-------------------|
| Mutationer | Magi/Besvärjelser |
| Arketyp | Yrke/Klass |
| Artefakt | Magiskt föremål |
| Skrot | Guld/Silver |
| Rot | Magi-backlash |
| Zon | Vildmark/Dungeon |

## Mutant: År Noll ↔ Mutant 1984

### Systemskillnader
- 1984: BRP (d100-baserat), År Noll: Year Zero Engine (d6-pooler)
- 1984: STY, FYS, SMI, INT, PSY, KAR (som DoD)
- År Noll: STY, KYL, SMI, SKP (4 attribut)
- Omräkning: 1984 FV / 5 ≈ Year Zero färdighetspoäng
